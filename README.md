# SYS://MONITOR — CPU 监控中台 v3.0

Windows 进程监控与优化工具（HTA 单文件应用，双击即用，无需安装）。

## 功能特性

- **实时监控**：CPU / 内存占用、进程数、线程数、运行时长，每 3 秒自动刷新
- **科技风 HUD**：发光仪表盘、CPU 历史曲线、扫描线动画，支持明/暗主题切换
- **进程知识库**：自动标注每个进程的功能说明、占用原因、优化建议与风险等级
- **结束进程**：WMI 原生接口优先 → taskkill 降级 → UAC 提权三级策略，结束后二次验证并即时反馈（Toast）
- **管理员权限**：内置权限检测与一键提权重启，提权后结束进程不再弹 UAC
- **一键优化**：高 CPU 进程批量降优先级（只调优先级，不结束进程）
- **交互**：搜索过滤、点击排序、右键菜单（详情 / 优先级 / 文件位置 / 复制 / 结束）

## 使用方法

1. 双击 `SystemMonitor.hta` 运行（依赖系统自带 mshta，无需任何安装）
2. 程序启动时自动检测权限：
   - **普通权限**：可结束当前用户启动的进程
   - 点击顶部 **「普通权限」徽章 → 以管理员身份重启**，UAC 确认一次后即可结束绝大多数进程
3. 右键进程行打开操作菜单；单击行查看进程详情

## 安全与风险保护

- 系统关键进程（System、csrss、wininit、lsass 等）**强制禁止结束**，保护规则不受权限影响
- 所有结束操作需二次确认，并标注风险等级（低 / 中 / 高 / 禁止）
- 程序仅在本机运行，不做任何网络行为

## 技术说明

- 单文件 HTA（HTML + CSS + JScript），运行于 Windows 内置 IE 内核
- 进程查询与操作全程异步，不阻塞 UI 线程
- 已针对 IE 内核做兼容：flex gap 替换为 margin 方案、`inset` 简写替换为四边定位
